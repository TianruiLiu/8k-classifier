# 8-K classifier: prompting vs. fine-tuning on SEC filings

Multi-label classification of SEC Form 8-K filings into event types (Item codes), comparing a TF-IDF baseline, a prompted frontier LLM and a LoRA fine-tuned small model on accuracy, cost and latency.

Current results and method: [RESULTS.md](RESULTS.md). Status: dataset and baseline done; LLM and fine-tuning comparisons in progress.
